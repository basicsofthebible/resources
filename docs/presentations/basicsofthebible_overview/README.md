# Basics of the Bible — Portfolio Preview

An interactive, single-file HTML slide presentation providing a visual overview of the resources and infographics available at [basicsofthebible.org](https://basicsofthebible.org).

## Live Presentation

- [Basics of the Bible — Portfolio Preview](https://basicsofthebible.github.io/resources/presentations/basicsofthebible_overview/)

## Overview

The presentation highlights three main areas:

1. **Bible Structure and Timeline (BST)** — Chronological visual guides for the Old and New Testaments, along with available translations.
2. **Basics of the Bible Study Guide (BBSG)** — A self-directed reading plan and study guide (*The Basics*, *Dig Deeper*, *Next Steps*, and translations).
3. **Bible Visualizations** — Selected infographics including historical timelines, Acrostic Psalms, the structure of Revelation, and *Job & Kings in Color*.

## Features

- **Interactive Navigation**: Left-hand section sidebar, interactive topic cards, and slide controls.
- **Presentation Mode**: Toggle to hide the navigation sidebar for a full-width stage view.
- **Theme Support**: Light and dark mode toggle.

## Contents

- `index.html` — Single-file HTML, CSS, and JavaScript presentation.
- `images/` — Visual assets and high-definition infographic previews used across the slides.
