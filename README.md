# Basics of the Bible — Resources

This repository contains interactive Bible study resources, supporting datasets, and documented workflows developed for [basicsofthebible.org](https://basicsofthebible.org).

The materials are organized into two main directories: published resources and the workflows used to create, analyze, and translate them.

## Published Resources

**[docs/](docs/)** — Web-based resources and supporting files.

### Bible Structure and Timeline (BST) Interactive

An interactive, multilingual presentation of the Bible's 66 books, arranged chronologically. Includes historical context, events, people, and Scripture references across 22 languages.

- [Launch BST Interactive](https://basicsofthebible.github.io/resources/bstinteractive/)
- [Project documentation and downloadable dataset](docs/bstinteractive/README.md)
- [Interactive graph visualizations](docs/bstinteractive/README.md#interactive-graph-visualizations)

## Workflows

**[workflows/](workflows/README.md)** — Reusable Python notebooks, supporting code, datasets, and examples documenting how selected resources were produced.

Current areas include:

- **[Translation workflows](workflows/translation/README.md)** — Translating SVG graphics, Word documents, and PowerPoint presentations while preserving their underlying structures and formatting.
- **[SVG translation and Chinese conversion](workflows/translation/svg/README.md)** — Examples for translating structured SVG graphics and converting between Simplified and Traditional Chinese.
- **[Revelation cross-reference analysis](workflows/revelation/README.md)** — Notebooks and datasets for examining biblical cross-references involving the Book of Revelation.

Each workflow provides its own documentation, requirements, and instructions.
